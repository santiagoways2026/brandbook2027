# Buzón de entrada

Deja aquí los HTML y CSS que quieras catalogar. Luego pide: **«cataloga el inbox»**.

## Qué dejar

- **HTML**: el bloque tal y como lo usas hoy en la web, con sus clases reales.
  Un archivo por bloque, o un archivo con varios bloques separados por comentarios.
- **CSS** (importante): la hoja de estilos donde viven esas clases, o el trozo que las define.
  Sin el CSS, el bloque se cataloga igual, pero el estilo tenemos que reconstruirlo y
  no será idéntico al tuyo.

## Cómo sacar el CSS de tu web

Si es WordPress, suele estar en Apariencia → Personalizar → CSS adicional, o en el
`style.css` del tema hijo. Si no lo encuentras, dilo y lo extraemos del sitio en vivo.

## Nombres

No hace falta un nombre concreto. Si puedes, algo descriptivo: `tabla.html`, `caja-aviso.html`,
`card-ruta.html`. Los archivos de este buzón se borran una vez catalogados.
