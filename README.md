# Santiago Ways · Brandbook 2027

Material de trabajo del rebranding continuista de Santiago Ways.

- `logos/`: logotipo horizontal e isotipo en vectorial (SVG), extraídos del brandbook 2025. Versiones blanco, verde Camino (#668814), verde Ways (#7AA606) y bosque (#1E2A12).
- `investigacion/competencia.md`: análisis de competencia y hueco de posicionamiento.
- `tokens/color.json`: paleta propuesta (blanco, dos verdes, grafito, gris y niebla), con usos y contrastes.
- `recursos/`: la concha recortada (`recorte_*.svg`) como recurso principal, y versiones anteriores descartadas (rayos y senda).
