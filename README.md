# Santiago Ways · Brandbook 2027

Repositorio de trabajo del Brandbook 2027: el documento de marca, las aplicaciones de prueba por canal y los entregables listos para usar.

## Qué hay aquí

| Carpeta / archivo | Contenido |
|---|---|
| `Santiago_Ways_Brandbook_2027.pdf` | El brandbook: estrategia, logo, color, tipografía, imagen y aplicaciones. |
| `aplicaciones/` | Catálogo navegable con todas las piezas de prueba (Instagram, reels, TikTok, email, YouTube, motion graphics, web y dossier). Abrir `aplicaciones/index.html`. |
| `aplicaciones/video/` | Todas las piezas animadas en MP4 (reels, TikToks y cartelas de YouTube), listas para descargar. |
| `entregables/email-xacobeo-2027/` | HTML listo para enviar de la campaña Xacobeo 2027 (nuevos clientes y viajeros frecuentes) con sus imágenes. |
| `entregables/email-reserva-xacobeo-2027/` | Campaña de reserva Xacobeo 2027: 2 emails en HTML listo para enviar con sus imágenes. |
| `entregables/youtube-ano-santo-2027/` | Miniaturas (1280 × 720) del vídeo «Guía del Año Santo 2027» y portadas de 4 Shorts (1080 × 1920). |
| `entregables/carrusel-100k/` | Carrusel de celebración de los 100K en Instagram: 6 PNG a 1080 × 1350 y PDF para importar en Canva. |
| `plantillas/word/` | **Plantilla de Word** sobria para todos los documentos: `.dotx` para instalar en Word, documento en blanco y 10 páginas tipo (portadas, índice, separador, texto, tabla, infografía, listas, imágenes y contraportada). Instrucciones en `plantillas/word/LEEME.md`. |
| `emails/` | Email «Tu Camino sin literas ni sorpresas» (subido antes; ver nota en `guias/pendientes.md`). |
| `guias/reglas-aplicaciones.md` | **Lo más importante**: cómo aplicar la marca en cada canal, con todas las decisiones tomadas a partir del feedback. |
| `guias/subtitulos-ugc.md` | Especificación del tema de subtítulos para reels UGC. |
| `guias/pendientes.md` | Lo que el brandbook todavía no fija y las decisiones abiertas. |

## Cómo ver el catálogo

- **En local:** descarga o clona el repositorio y abre `aplicaciones/index.html` en el navegador. Las fuentes, fotos y vídeos van dentro de la carpeta, así que funciona sin conexión.
- **Versión publicada:** el mismo catálogo está publicado como página privada en Claude (pídele el enlace a quien lo creó).
- Los botones «Descargar MP4» de la versión publicada no funcionan al abrir el archivo en local; en local, los vídeos están directamente en `aplicaciones/video/`.

## Estado

Todas las piezas son **pruebas para validar el brandbook, no piezas aprobadas para publicar**. Textos, nombres, cifras de «me gusta» y visualizaciones son de ejemplo salvo donde se indica. Las fotos son provisionales y varias son de banco de imagen.
